# Present

A privacy-first attendance PWA using vanilla HTML/CSS/JavaScript and IndexedDB.

## Run locally
From this folder, run a local web server, for example:
`python3 -m http.server 8000`
Then open `http://localhost:8000`.

## GitHub Pages
Create a GitHub repository, upload these files, then enable Pages from the repository's Settings → Pages → Deploy from branch → main → /(root).

## iPhone
Open the deployed HTTPS URL in Safari, tap Share → Add to Home Screen.

## Data
Attendance is stored locally in IndexedDB. Use Settings → Export for a JSON backup.
